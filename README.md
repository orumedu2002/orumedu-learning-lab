# 교육채널 오름 | Learning Lab

뇌과학·학습과학·자기조절학습에 관한 연구를 교육 현장의 언어로 번역하는 GitHub Pages 블로그입니다.

- 공개 사이트: `https://orumedu2002.github.io/orumedu-learning-lab/`
- 운영자: 백주경 교육학 박사
- 게시 원칙: [운영 원칙](methodology.md)

## 매일 발행 워크플로

1. 국내외 공신력 있는 출처에서 후보 주제 5개를 찾습니다.
2. 출처 신뢰도, 최신성, 브랜드 적합성, 교육적 실용성, 과장 위험을 점수화합니다.
3. 최고 점수 후보 1개를 선정합니다.
4. 출처를 교차 확인해 초안을 작성합니다.
5. 의료적·임상적 표현, 뇌파 해석, 인용·통계는 특히 보수적으로 검토합니다.
6. 검증된 글만 `_posts/`에 Markdown으로 게시합니다.

## 로컬 미리보기

GitHub Pages의 Jekyll 기본 구성을 사용합니다. Ruby/Jekyll 환경이 있으면 저장소 루트에서 다음을 실행합니다.

```bash
bundle exec jekyll serve
```

## 콘텐츠 안전 원칙

- 의학적 진단이나 치료를 주장하지 않습니다.
- 뇌파 측정은 학습상담의 보조적 관찰 자료로만 다룹니다.
- 확인되지 않은 수치·인용·연구결과는 게시하지 않습니다.
- 정신건강 위기 또는 임상적 평가가 필요한 경우, 적절한 전문기관 연계를 안내합니다.
